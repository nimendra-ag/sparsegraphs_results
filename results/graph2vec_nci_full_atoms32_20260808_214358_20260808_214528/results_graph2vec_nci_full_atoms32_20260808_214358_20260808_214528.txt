                       both classes count equally regardless of size.
  Baseline             what a knowledge-free model scores in the Macro
                       column: the best trivial constant classifier for
                       Precision / Recall / F1 / Accuracy, and a random
                       ranker for PR-AUC, ROC-AUC and MCC. Metrics whose
                       floor differs by class are listed again per class
                       under each model.
  Accuracy             identical across all three columns by construction

                       same for both classes); split for a uniform layout.

                       everywhere forces its recall to 1.0 — so only the
                       macro floor of 0.5 is meaningful.
